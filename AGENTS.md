# AGENTS.md

## Progetto
Lavora esclusivamente su Post Automatici.

## Stack
Lovable + GitHub + Vercel. GitHub `main` è la fonte unica del codice.

## Priorità
Prima rendere il prodotto completamente utilizzabile per uso personale. Pagamenti, landing commerciale, clienti esterni e SaaS multiutente vengono dopo.

## Regole funzionali
- Profili/attività illimitati e indipendenti.
- Dati, brand, sito, settore, social, contenuti, calendario, metriche e apprendimento separati per profilo.
- Analisi sito pagina per pagina.
- OpenAI per i contenuti; immagini solo tramite il modello OpenAI Images scelto per il progetto.
- Social target: Instagram, Facebook, LinkedIn, Google Business Profile.
- Non simulare integrazioni live. Se mancano API/credenziali mostra `Da configurare`.
- Metriche reali soltanto; niente numeri casuali in modalità reale.
- QA mobile/iPhone obbligatorio.

## Metodo
Problema -> correzione -> verifica -> PASS -> problema successivo.
Non dichiarare PASS senza una verifica riproducibile.
