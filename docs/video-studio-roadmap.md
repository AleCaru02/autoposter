# Personal Video Studio

Scope: single-user only. Preserve existing editorial, approval, and publishing systems.

Phase 1: inspect existing integrations and build a 30-day editorial planner with evidence and asset provenance.
Phase 2: add storyboard JSON and a local FFmpeg-based vertical video renderer with preview and subtitles.
Phase 3: evaluate licensed voice and talking-avatar models on available Windows hardware; use optional cloud only with explicit approval and a 30 EUR monthly hard cap.
Phase 4: connect reviewed videos to the existing approval and publication workflow with idempotent jobs and regression tests.

Do not deploy, spend money, upload personal biometric assets, or publish automatically without user approval. Validate third-party licenses before installation.
