# Video engine selection — personal use only
Selected trial: Abekyo Editor (MIT) as a separately running local rendering service, with a narrow JSON adapter to Post Automatici. Do not copy its Next.js application into the Vite UI or expose local render endpoints publicly. Validate API schema and Windows performance before connecting.
Alternatives: Rendiv (Apache-2.0) for independent React rendering; Remotion for motion graphics subject to its source-available license and the user's eligibility. Official Remotion Timeline is paid and excluded from the 30 EUR/month plan.
Voice candidate: Chatterbox Multilingual V3; test Italian pronunciation and speaker similarity with consent and review model-weight terms.
Cloud avatar: disabled by default, explicit per-job approval, 30 EUR/month hard cap, verify GPU hours and currency conversion before dispatch.
Production safeguards: no automatic publication, no personal media uploads without consent, license provenance for all media, review gating, idempotent render job identifiers.
Source references: https://github.com/abekyo/abekyo-editor ; https://github.com/thecodacus/rendiv ; https://github.com/resemble-ai/chatterbox ; https://www.remotion.dev/docs/terms
